# Сақталған стильдер

Екі стиль сақталды. Екеуі де `config.json` арқылы қосылады, шрифттері `fonts/` қалтасында тұр (SIL OFL лицензиясымен, тегін).

---

## 1. NEON LIME: референс Reels стилі

Сіз жіберген референс видеодан алынды. Сөйлеп тұрған адам (talking head) және UI-графика.

**Қосу:** `config.neon.example.json` файлын көшіріп алыңыз, ал субтитрге `"subtitles": {"preset": "neon_lime"}` жазыңыз.

| Элемент | Мәні |
|---|---|
| Акцент түсі | неон лайм `#D6FD3D` |
| Фон (interlude) | `#111111`, астынан әлсіз лайм жарқыл, ұшып жүрген шаршы бөлшектер |
| Карточка | `#181818`, жиегі `#444`, бұрышы 34 px |
| Негізгі шрифт | Montserrat Black, БАС ӘРІП, ақ, жұқа қара жиек |
| Кіші жазу | Montserrat SemiBold, лайм, жарқылмен (glow) |
| Субтитр | 3 сөзден, айтылып жатқан сөз лайм түсті, сәл үлкейеді |

**Графика түрлері** (`graphics` ішінде, уақыт түпнұсқа видео бойынша, секундпен):

| type | Не көрсетеді | Негізгі өрістер |
|---|---|---|
| `neon_headline` | Кіші лайм жазу + үлкен «НЕ ҮШІН» + лайм рамка + «?» | `word`, `label`, `accent`, `y` |
| `neon_tag` | Лайм не қызыл таңба («айналмайды», «5 жыл», «емес») | `text`, `color: lime/red` |
| `neon_label` | Тек лайм жазу («себебі», «бірақ») | `text` |
| `neon_stat` | Instagram карточкасы: Reels · қаралым ▶ 1 000 000 000 | `title`, `sub`, `value`, `icon` |
| `neon_wallet` | Әмиян карточкасы: шотың / KZT / 0 ₸ / ✕ | `title`, `currency`, `value`, `cross` |
| `neon_checklist` | ✓ / ✕ тізімі, элементтер айтылған сайын шығады | `title`, `items: [[уақыт, мәтін, true/false]]` |
| `neon_tree` | «ПОЗИЦИЯ» тармақ-диаграммасы | `root`, `label`, `items: [[уақыт, мәтін, icon]]` |
| `neon_arrow` | Сызылып шығатын лайм көрсеткі | `length` |
| `neon_counter` | Санап өсетін лайм сан | `from`, `to`, `suffix` |
| `neon_interlude` | Видеоның орнына қара фон (графикаға арналған экран) | `start`, `end` |

**Анимациялар:** pop (back-out), төменнен шығу, сызықтың сызылуы, тізім элементтерінің кезекпен шығуы.

**Орналасу ережесі:** субтитр экранның 0.77 биіктігінде тұрады. Графиканы `y ≤ 1230` аймағына қойыңыз, сонда субтитрмен қабаттаспайды.

## 2. PREMIUM EDITORIAL: жайнамаз роликінің стилі

`projects_examples/premium_reels_jainamaz.py` скриптінде жүзеге асырылған.

| Элемент | Мәні |
|---|---|
| Шрифт 1 | Montserrat ExtraBold/Black: үлкен акцент сөздер (ӨТЕ КӨП, АКЦИЯҒА) |
| Шрифт 2 | Cormorant Garamond SemiBold Italic: эмоциялық сөздер («арзан жайнамаз бар ма?») |
| Түстер | ақ `#FFFFFF`, кілегей `#FFF9EE`, алтын `#F0D296` |
| Обводка | жоқ. Оның орнына жұмсақ көлеңке және мәтін астында күңгірт «frosted» фон |
| Transition | dissolve, whip (motion blur), zoom, mask reveal, slide, match cut |
| Motion | алтын сызықтар, сызылатын ескі баға, санап өзгеретін баға, теңдеу, Telegram ұшағы |
| Түс | табиғи. Тек HDR → SDR, қанықтық ≈1.03 |

Субтитр preset-і: `"subtitles": {"preset": "premium_editorial"}`.
